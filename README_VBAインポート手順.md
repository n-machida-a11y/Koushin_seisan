# VBAモジュール インポート手順

`生産計画_マクロ.xlsm` に VBA コード一式を取り込む手順です。
**初回セットアップ時に1回だけ**、または **コードを更新した時** に実施します。

---

## 全体像

```
[GitHub から取得した一式]              [Excelブック]
                                      生産計画_マクロ.xlsm
  vba/
    ├─ ModLoader.bas      ──────►   ┌─────────────────┐
    ├─ ModConfig.bas                │ ModLoader を     │
    ├─ ModMain.bas                  │ 1回だけ手動で    │
    ├─ ModStep05.bas                │ 取り込む         │
    ├─ ...                          │   ↓             │
    └─ ModStep26.bas                │ ボタンで一括    │
                                    │ インポート実行  │
                                    └─────────────────┘
```

**ポイント**: 24個のモジュールを1個ずつ手作業で取り込む必要はありません。
**ModLoader.bas だけ最初に取り込めば**、後はボタン1回で全部入ります。

---

## 方法は2つ

| 方法 | 所要時間 | こんな人向け |
|------|---------|-------------|
| **方法A: ローダーで一括** ⭐ | 約2分 | 普段使い・更新時 |
| 方法B: 1個ずつ手動 | 約5分 | ローダーが使えない環境 |

---

# 方法A: ローダーで一括インポート（推奨）

## ステップ1: トラストセンターの設定（初回のみ・1分）

VBAコードから自身のVBAプロジェクトを書き換える権限を許可します。

1. Excel を起動
2. `ファイル` → `オプション`
3. 左メニュー `トラストセンター` → `トラストセンターの設定` ボタン
4. 左メニュー `マクロの設定`
5. **「VBAプロジェクトオブジェクトモデルへのアクセスを信頼する」** にチェック
6. `OK` → `OK`

> ✓ 一度設定すれば、以降は不要です。

## ステップ2: ファイル配置

`生産計画_マクロ.xlsm` と `vba\` フォルダを **同じ親フォルダ** に置きます。

```
任意の作業フォルダ\
  ├─ 生産計画_マクロ.xlsm    ← Excelブック
  └─ vba\                    ← .bas ファイル一式
      ├─ ModLoader.bas
      ├─ ModConfig.bas
      └─ ...
```

> ✓ 配置が違うと「vba フォルダが見つかりません」エラーになります。

## ステップ3: ModLoader を1個だけ取り込む（1分）

1. `生産計画_マクロ.xlsm` をダブルクリックで開く
2. `Alt + F11` で VBAエディタ (VBE) を開く
3. 上部メニュー `ファイル` → `ファイルのインポート` を選択
4. `vba\ModLoader.bas` を選んで `開く`
5. 左の「プロジェクト」ウィンドウに `ModLoader` が表示されればOK

## ステップ4: ボタン1回で全モジュール取り込み（30秒）

1. VBE のままで `ModLoader` をダブルクリック
2. コード内のどこかをクリックしてカーソルを置く
3. `F5` キーを押す（または上部メニュー `実行` → `Sub/ユーザーフォームの実行`）
4. ダイアログで `VBA一括インポート` を選び `実行`
5. **「成功: 24 件」** と出たら成功 → `OK`
6. `Ctrl + S` でブックを保存

> ✓ これで全部のVBAコードが入りました。

## ステップ5: 実行ボタンを作る（初回のみ・1分）

「設定」シートに「▶ メイン実行」ボタンを置きます。

1. Excelに戻り（`Alt + F11`）、`設定` シートを開く
2. `開発` タブ → `挿入` → `ボタン（フォームコントロール）`
3. シートの好きな場所にドラッグでボタンを描画
4. マクロ割り当てダイアログで `メイン実行` を選び `OK`
5. ボタン上で右クリック → `テキストの編集` → `▶ メイン実行` と入力

---

# 毎月の運用

1. BHプラン出力ファイル（xlsx）を `input\` フォルダに置く
2. `生産計画_マクロ.xlsm` を開く
3. `▶ メイン実行` ボタンをクリック → Phase 1-A 実行
4. 続けて Phase 1-B1、Phase 1-B2 のボタンも順にクリック
5. `ログ` シートで結果を確認

---

# コードを更新したい時

GitHubから最新の `vba\` フォルダを取得した後:

1. `生産計画_マクロ.xlsm` を開く
2. `Alt + F11` → `ModLoader` をダブルクリック
3. `F5` → `VBA一括インポート` を実行
4. 既存モジュールは自動で置き換わります
5. `Ctrl + S` で保存

> ✓ 古いコードを手動で消す必要はありません。同名モジュールは自動削除→再取り込みされます。

---

# クリーンインポート（おかしくなった時の最終手段）

「動作が変」「謎のエラー」となった時:

1. `Alt + F11` → `ModLoader` をダブルクリック
2. `F5` → `VBA全モジュール削除` を実行（確認ダイアログで「はい」）
3. 続けて `F5` → `VBA一括インポート` を実行
4. `Ctrl + S` で保存

`ModLoader` 自身と「ThisWorkbook」「Sheet1」等は残るので安全です。

---

# 設定変更

「設定」シートの B 列を直接書き換えてください。コード変更は不要です。

| 項目 | 例 | 説明 |
|------|-----|------|
| `BHプラン保存フォルダ` | `P:\生産計画\input\` | 入力xlsxの置き場所 |
| `BH計画保存版_V8パス` | `P:\保存版\V8_BH計画保存版.xlsx` | V8の保存版 |
| `BH計画保存版_V9パス` | `P:\保存版\V9_BH計画保存版.xlsx` | V9の保存版 |
| `BH計画保存版_V8_KPNo列番号` | `13` | V8保存版のKP-No列番号（M列=13） |
| `BH計画保存版_V9_KPNo列番号` | `10` | V9保存版のKP-No列番号（J列=10） |

# よくあるトラブル

| 症状 | 原因 | 対処 |
|------|------|------|
| 「プログラムによるVisual Basicプロジェクトへのアクセスは信頼性に欠けます」 | トラストセンター未設定 | ステップ1を実施 |
| 「vba フォルダが見つかりません」 | xlsmとvba\の配置違い | ステップ2の配置を確認 |
| 「Mod***.bas が見つかりません」 | ファイル名違い・取得漏れ | GitHubから `vba\` フォルダ全体を再取得 |
| 「マクロが見つかりません」 | インポート未完了 | ステップ4を実施 |
| 「inputフォルダにxlsxが見つかりません」 | 入力ファイル未配置 | BHプラン出力を `input\` に置く |
| 「シートが見つかりません」 | 設定シートの値ズレ | `加工対象シート名` を実シート名に合わせる |
| 処理が途中で停止（黄色ハイライト） | 当月内のT-No変更検出 | ログ確認 → 担当者問い合わせ → データ修正 → 再実行 |
