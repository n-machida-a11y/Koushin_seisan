# Phase 1-A バグ修正 検証手順書

対象コミット: `4e7dca8` — Step08行展開のデータ破壊バグ修正・全ステップの堅牢性向上

---

## 事前準備

### 1. テスト用データの作成

**本番データを絶対に使わないこと。** 必ずコピーを使う。

1. BHプランの出力ファイル（xlsx）をコピーして `input\` フォルダに配置
2. BH計画保存版（V8/V9）もコピーを用意（設定シートのパスをコピー先に変更）
3. `生産計画_マクロ.xlsm` もバックアップを取っておく

### 2. VBAモジュールの更新

修正した5ファイルをVBEに再インポートする:

1. `生産計画_マクロ.xlsm` を開く → `Alt + F11` でVBEを開く
2. 以下のモジュールを **右クリック → 削除（エクスポートしない）** してから再インポート:

| モジュール | 修正内容 |
|-----------|---------|
| ModError.bas | Application状態復元追加 |
| ModMain.bas | パフォーマンス最適化 + エラーハンドラ |
| ModStep08.bas | 行展開バグ修正 + 数値チェック |
| ModStep09.bas | 数値チェック追加 |
| ModStep10.bas | ログ行数カウント修正 |

3. Ctrl+S で保存

## テストケース

### テスト1: Step08 行展開（致命的バグ修正の確認）

**目的:** 数量2以上の試作製造行が正しく展開され、周囲の行が破壊されないこと

#### テストデータ準備

BHプラン（inputフォルダのxlsx）に以下のようなデータを用意する:

| 行 | B列(生産計画No) | F列(機種名) | L列(数量) | N列(出荷日) |
|----|----------------|------------|----------|------------|
| 4  | （ヘッダー行） | | | |
| 5  | P001 | 試作製造A | 1 | 2026-04-15 |
| 6  | P002 | 試作製造B | **2** | 2026-04-20 |
| 7  | P003 | 試作製造C | **3** | 2026-05-01 |
| 8  | D001 | 通常機種 | 5 | 2026-06-10 |
| 9  | D002 | 別の通常機種 | 1 | 2026-04-25 |

#### 実行手順

1. Step08のみ単体実行: VBEで `Step08_計画生産行展開` にカーソルを置き `F5`
   - ※事前に `設定読み込み` を実行しておくこと

#### 期待結果

| 行 | B列(生産計画No) | L列(数量) | 備考 |
|----|----------------|----------|------|
| 5  | P001 | 1 | 数量1なので展開なし |
| 6  | P002-01 | 1 | P002が2行に展開 |
| 7  | P002-02 | 1 | |
| 8  | P003-01 | 1 | P003が3行に展開 |
| 9  | P003-02 | 1 | |
| 10 | P003-03 | 1 | |
| 11 | D001 | 5 | **変更なし（試作製造でないため）** |
| 12 | D002 | 1 | **変更なし** |

#### 確認ポイント

- [ ] P002が2行（-01, -02）に正しく展開されている
- [ ] P003が3行（-01, -02, -03）に正しく展開されている
- [ ] **行11（D001）と行12（D002）のデータが破壊されていない** ← 旧バグの核心
- [ ] 展開された全行の数量が1になっている
- [ ] ログシートに「2件の行展開を実施しました」と記録されている

### テスト5: エラーリカバリ（安全停止）

**目的:** 予期しないエラー時にファイルが破損状態で保存されないこと

#### テストデータ準備

意図的にエラーを発生させる:
- 設定シートの `加工対象シート名` を存在しないシート名（例: `存在しない`）に一時変更

#### 実行手順

1. 実行ボタンでメイン実行
2. エラーダイアログを確認

#### 期待結果（シート名不一致の場合）

- [ ] 「シートが見つかりません」ダイアログが表示される
- [ ] ファイルが保存されていない（元のデータが無傷）

#### 追加テスト（処理途中のエラー）

1. 設定シートの `列番号_数量(L列)` を存在しない列番号（例: `999`）に変更
2. メイン実行

#### 期待結果

- [ ] エラーダイアログ「予期しないエラーが発生しました。ファイルは保存されていません。」が表示
- [ ] BHプランファイルが**保存されずに閉じられている**
- [ ] ログシートに「予期しないエラー」が記録されている
- [ ] Excel の画面更新・自動計算が正常に復帰している（固まっていない）
