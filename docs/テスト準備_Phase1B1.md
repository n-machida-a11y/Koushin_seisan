# 生産計画自動化 通しテスト手順書（Phase 1-A + Phase 1-B）

## 概要

BHプランの生データに対して、Step⑤〜㉖（自動化済みステップ）を順番に実行し、
各ステップが正しく動作するかを確認する通しテストの手順です。

※ Step⑪⑫⑯⑲㉓は人の判断が必要なため、今回のテスト対象外です。

---

## 事前準備

### 1. テストデータの準備
- **本番データを絶対に直接使わないこと。必ずコピーを使う。**
- input フォルダにBHプラン（xlsx）を配置
- V8/V9 Production Schedule、星取表計算マスター、0110BHPlanのコピーを用意
- 設定シートの各パスをテスト用コピーに向ける

### 2. VBAモジュールのインポート
VBEで `全モジュール再インポート` を実行して最新版に更新

### 3. テスト実行用コード
VBEの標準モジュールに以下を貼り付ける:

```vba
Sub 通しテスト()
    Call 設定読み込み

    Dim targetWb As Workbook
    Dim folderPath As String
    folderPath = g_BHPlanFolder
    If Right(folderPath, 1) <> "\" Then folderPath = folderPath & "\"

    Dim fileName As String
    Dim latestFile As String
    Dim latestDate As Date
    fileName = Dir(folderPath & "*.xlsx")
    Do While fileName <> ""
        Dim fd As Date
        fd = FileDateTime(folderPath & fileName)
        If fd > latestDate Then
            latestDate = fd
            latestFile = fileName
        End If
        fileName = Dir()
    Loop
    If latestFile = "" Then
        MsgBox "inputフォルダにxlsxがありません"
        Exit Sub
    End If

    Set targetWb = Workbooks.Open(folderPath & latestFile)
    Dim targetWs As Worksheet
    Set targetWs = targetWb.Sheets(g_TargetSheetName)

    Application.ScreenUpdating = False
    Application.Calculation = xlCalculationManual
    Application.EnableEvents = False

    ' ===== Phase 1-A: データ加工（Step05〜10）=====
    Call Step05_計画生産対象削除(targetWs)
    Call Step06_出荷済みデータ削除(targetWs)
    Call Step07_型式補完(targetWs)
    Call Step08_計画生産行展開(targetWs)
    Call Step09_数量チェック(targetWs)
    Call Step10_並び替え(targetWs)

    ' ===== Phase 1-B1: 集計・転記（Step13〜20）=====
    Call Step13_集計表作成(targetWs)
    Call Step14_出荷完了計画日付追加(targetWs)
    Call Step15_出荷台数入力(targetWs)
    Call Step17_V8マスター更新(targetWs)
    Call Step18_V9マスター更新(targetWs)
    Call Step20_グラフ更新(targetWs)

    ' ===== Phase 1-B2: KMP関連（Step21〜26）=====
    Call Step21_KMPユニット必要台数(targetWs)
    Call Step22_KMPシップメント更新(targetWs)
    Call Step24_KMP出荷スケジュール更新(targetWs)
    Call Step25_KMP_MPS更新(targetWs)
    Call Step26_Forecast完成(targetWs)

    Application.ScreenUpdating = True
    Application.Calculation = xlCalculationAutomatic
    Application.EnableEvents = True

    targetWb.Save

    MsgBox "通しテスト完了。ログシートを確認してください。"
End Sub
```

## 各ステップの説明と確認ポイント

### Phase 1-A: データ加工（BHプランの中身を整理する）

#### Step⑤: 計画生産対象の削除
**何をするか:**
追加仕様(K列)に「計画生産対象」と書かれているデータを削除する。
これらは計画段階のデータで、実際の生産データではないため除外する。

**確認ポイント:**
- [ ] ログに「X行を削除しました」と表示される
- [ ] K列に「計画生産対象」を含む行が残っていないこと

---

#### Step⑥: 出荷済みデータの削除
**何をするか:**
光真ss出荷日(N列)が当月より前（＝過去）のデータで、KP-No(R列)がBH計画保存版（V8/V9）に
存在するものを「出荷済み」とみなして削除する。
オムロン側のデータは出荷しても消えずに残るため、こちらで消し込みを行う。

**確認ポイント:**
- [ ] ログに「X行を削除しました」と表示される
- [ ] 過去の出荷日かつ保存版にKP-Noがある行が削除されていること
- [ ] 保存版にKP-Noがない行は残っていること（誤削除なし）

---

#### Step⑦: BH型式TYPE(S列)の補完
**何をするか:**
S列が空欄の行に型式を自動補完する。補完ルール:
1. G列（型式）が「YB-」または「YU-」で始まる → そのままS列に使用
2. それ以外 → 同じ客先名(C列)の行からS列の値を探して補完
3ヶ月以内で補完できない場合はオムロンへの問い合わせが必要（処理停止）。
4ヶ月以降は警告のみで続行。メンテ行（機種名に「メンテ」を含む）はスキップ。

**確認ポイント:**
- [ ] ログに「X行を補完、Y行を警告スキップ」と表示される
- [ ] 3ヶ月以内のデータでS列が空のまま残っていないこと（メンテ行除く）
- [ ] メンテ行はS列が空のままスキップされていること

---

#### Step⑧: 計画生産行の展開（1台1行化）
**何をするか:**
機種名(F列)に「計画生産」と書かれた行で、3ヶ月以内かつ数量が2以上のものを
台数分の行にコピー展開する。例: 数量3 → 3行に展開し、
生産計画No(B列)に「-01」「-02」「-03」と連番を付ける。
納品できない台数の場合は納期をばらして1台1行にするためのステップ。

**確認ポイント:**
- [ ] ログに「X件の行展開を実施しました」と表示される
- [ ] 展開された行の数量がすべて1になっていること
- [ ] 連番（-01, -02, -03...）が正しく付いていること
- [ ] 4ヶ月以降の行は展開されていないこと

---

#### Step⑨: 数量チェック（V8/V9）
**何をするか:**
MODEL(U列)が「V8」「V9」で3ヶ月以内の行の数量(L列)が1であることを確認する。
計画生産以外のデータで数量が1でない場合はオムロンへの問い合わせが必要。
※メンテV8/V9は数量1以上でもOK

**確認ポイント:**
- [ ] ログに「V8/V9の3ヶ月以内数量チェック完了」と表示される
- [ ] エラーで停止しなければOK

---

#### Step⑩: 並び替え
**何をするか:**
全データを以下の優先順位で並び替える:
- V8/V9: MODEL → 光真出荷日 → 順序指示発行日 → KP-No → 属性(降順) → 客先名 → 生産計画No
- メンテV8/V9: MODEL → 機械品番 → 光真出荷日 → 順序指示発行日 → KP-No

**確認ポイント:**
- [ ] ログに「並び替え完了（X行）」と表示される
- [ ] MODEL列でグループ化されていること（V8→V9→ﾒﾝﾃV8→ﾒﾝﾃV9の順）

---

### Phase 1-B1: 集計・転記（加工したデータを各ファイルに反映する）

#### Step⑬: V8/V9集計表の作成
**何をするか:**
BHプランのMODEL=V8/V9のデータから、光真出荷日ごと・BH型式TYPEごとの数量を集計し、
V8 Production Scheduleの「0110集計」シートのS列以降に書き込む。
ピボットテーブル相当の処理。当月以降のデータのみが対象。

**確認ポイント:**
- [ ] ログに「X件の集計データを書き込みました（BH型式: Y種類、日付: Z件）」と表示される
- [ ] 0110集計シートのS列以降にBH型式ごとの台数が入っていること

---

#### Step⑭: 出荷・完了計画への日付追加
**何をするか:**
V8/V9のProduction Scheduleの「出荷・完了計画」シートに、当月から3ヶ月後までの
日付行を追加する。各行にはA列(年月)、B列(日付)、C列(曜日)、D列(稼働日フラグ○/×)を設定。
既に存在する日付は追加しない。

**確認ポイント:**
- [ ] ログに「V8: X日追加、V9: Y日追加」と表示される
- [ ] 出荷・完了計画シートのB列に当月〜3ヶ月後の日付が入っていること
- [ ] D列に○（平日）/×（土日）が入っていること

---

#### Step⑮: 順序指示出荷台数の入力
**何をするか:**
BHプランの出荷日ごとのV8/V9台数を集計し、出荷・完了計画シートの
E列（順序指示出荷台数）とG列（出荷台数LAZ計）に転記する。
0110BHPlanの集計データを元に台数を入力する処理。

**確認ポイント:**
- [ ] ログに「V8: X日分、V9: Y日分の出荷台数を入力」と表示される
- [ ] 出荷・完了計画のE列/G列に台数が入っていること

---

#### Step⑰: V8星取日程マスター更新
**何をするか:**
BHプランのMODEL=V8のデータを星取表計算マスターの「V8星取日程マスター」シートに転記する。
列マッピング: T-No(W列)→A列、号機(AA〜AG列)→B〜H列、BH型式(S列)→I列、
順序確定日(M列)→J列、光真出荷日(N列)→K列。M列はすべて「・」を設定。
既存のT-Noは上書き、新規は末尾に追加。

**確認ポイント:**
- [ ] ログに「X行をV8星取日程マスターに転記しました」と表示される
- [ ] マスターシートに新しい行が追加されていること
- [ ] M列がすべて「・」になっていること

---

#### Step⑱: V9星取表日程マスター更新
**何をするか:**
Step⑰のV9版。BHプランのMODEL=V9のデータを「V9星取表日程マスター」シートに転記。
V9の号機はZ001,Z002,Y001,Y002（AA〜AD列）。

**確認ポイント:**
- [ ] ログに「X行をV9星取表日程マスターに転記しました」と表示される

---

#### Step⑳: BH出荷・完了グラフ更新
**何をするか:**
BHプランから月ごとのV8/V9出荷台数を集計し、V8 Production Scheduleの
「BH出荷・完了グラフ」シートに書き込む。B列=V8台数、C列=V9台数、D列=合計。
当月から+4ヶ月分を更新する。

**確認ポイント:**
- [ ] ログに「Xヶ月分のグラフデータを更新しました」と表示される
- [ ] グラフシートのB列(V8)、C列(V9)、D列(合計)に値が入っていること

---

### Phase 1-B2: KMP関連（フィリピン工場向けの出荷計画を更新する）

#### Step㉑: KMPユニット日当たり必要台数
**何をするか:**
V8 Production Scheduleの星取表シートから、コンポーネント列（LAA〜LCD）の
「・」マークを集計して、日ごとのKMPユニット必要台数を算出する。
V8の場合、LAA〜LAEはO列の日付、LBL以降はP列の日付が必要日。

**確認ポイント:**
- [ ] ログに「KMPユニット必要台数を集計（合計: Xユニット、Y日分）」と表示される

---

#### Step㉒: KMP SHIPMENT PLAN更新
**何をするか:**
V8 Production Scheduleの「KMP SHIPMENT PLAN」シートのTOTAL列(AC列)を
BHプランの日付ごとのV8出荷台数で更新する。

**確認ポイント:**
- [ ] ログに「X日分のKMP SHIPMENT PLANを更新しました」と表示される

---

#### Step㉔: KMP出荷スケジュール更新
**何をするか:**
KMP SHIPMENT PLANのAC列(TOTAL)の値を、KMP出荷スケジュールシートの
L列(V8台数)とM列(合計台数)に転記する。

**確認ポイント:**
- [ ] ログに「X日分のKMP出荷スケジュールを更新しました」と表示される

---

#### Step㉕: KMP MPS更新
**何をするか:**
BHプランのshipment month(V列)をキーに月ごとのV8/V9出荷台数を集計し、
KMP MPSシートに書き込む。先月の情報との変更点を割り出すためのデータ。

**確認ポイント:**
- [ ] ログに「Xヶ月分のKMP MPSデータを更新しました」と表示される

---

#### Step㉖: Forecastデータ完成
**何をするか:**
BHプランのshipment month(V列)をキーに、BP列(LAA101Q)以降のコンポーネント別台数を
集計してforecastデータを作成する。KMP forecast dataエクセルの完成に必要なデータ。

**確認ポイント:**
- [ ] ログに「Forecastデータ集計完了（Xヶ月、Yコンポーネント、Z件）」と表示される

## 未実装ステップ（Phase 1-B3: 今回はスキップ）

| Step | 内容 | スキップ理由 |
|------|------|-------------|
| ⑪ | メンテ行の星取表照合 | 一部一致時にオムロンへの問い合わせ判断が必要 |
| ⑫ | T-No/号機の連番付与・変更点検出 | 星取表との差分検出と影響度の人的確認が必要 |
| ⑯ | 平準化（生産台数の均等配分） | 1日10台MAX、ストア20台MAX等の制約調整に人の判断が必要 |
| ⑲ | 星取表の差し替え | 差替え範囲やスキップ条件の判断が必要 |
| ㉓ | KMP出荷計画 | 重量1〜1.5t、月1〜3便、前回確定分維持等の制約 |
